USB Controllers (B650M-P) – ReactOS

Install
  Download B650M-P-USB-ReactOS-Setup-i386.exe from the latest GitHub release.
  Run it in the matching ReactOS i386 system and follow required restarts.
  The installer includes runtime modules and notices; it contains no source archive.
  See packaging/INSTALL.txt for extraction, installation, resume and rollback.

Host build
  cmake -S . -B Binaries/.build/host -DXHCI_SANITIZERS=ON
  cmake --build Binaries/.build/host -j4
  ctest --test-dir Binaries/.build/host --output-on-failure
  Binaries/.build/host/xhci_inventory
  Host builds do not download ReactOS dependencies. Inventory reads identity only.
  If LeakSanitizer is unavailable under tracing, set ASAN_OPTIONS=detect_leaks=0;
  ASan/UBSan and LeakSanitizer qualification remain separately identified.

Native driver build (Linux, i686-w64-mingw32 GCC13)
  Install CMake 3.19+, GNU make or Ninja, and the MinGW i386 compiler toolchain.
  cmake -S . -B Binaries/.build/native -DXHCI_NATIVE_CONTROLLER=ON
  cmake --build Binaries/.build/native --target xhci_native_controller -j4
  Output: Binaries/.build/native/native/xhci-controller-i386.sys

  Configuration downloads only the pinned SDK dependencies into dependencies/:
  required headers, generated headers and kernel/HAL import libraries (about501KiB).
  The complete ReactOS source/build tree is not downloaded. dependencies.lock.json
  fixes the exact archive and individual file-manifest checksums. Cached files are
  verified and reused on subsequent configurations. The directory is gitignored.
  XHCI_DOWNLOAD_DEPENDENCIES=OFF supports an already populated offline cache.

  Add XHCI_NATIVE_DIAGNOSTIC=ON or XHCI_NATIVE_BOOT=ON for the separate diagnostic
  module or boot bridge. Diagnostic output must never be installed as the HCD.
  Add XHCI_NATIVE_USB_COMPATIBILITY=ON and build xhci_native_usb_compatibility to
  rebuild patched USBHUB/USBSTOR/disk/HIDUSB. Only that option fetches the additional
  upstream module source, link libraries/resources and host fixup tool (about470KiB).
  The automatic compatibility tool cache currently supports Linux x86_64 hosts.
  XHCI_IMAGE_TOOLS=ON separately fetches only the small FatFs image-tool component.

  Explicit matching XHCI_REACTOS_SOURCE and XHCI_REACTOS_BUILD paths still support
  an external SDK and bypass automatic downloads. Set both together. Experimental
  PnP kernel rebuilding remains separate and requires its explicitly audited SDK;
  the automatic driver dependencies contain no kernel implementation source.
  XHCI_BUILD_PACKAGE_BACKEND=ON builds the shared i386 GUI installer backend.
  See cmake/m09_m10.cmake for provider catalog and standalone packaging inputs.
  GCC13/MinGW i386 compilation is verified; MSVC compilation is not verified.

Scope
  Exact reviewed MSI PRO B650M-P PCI profiles and ReactOS i386 system-file hashes.
  The installer rejects unknown baseline files and does not install the experimental
  PnP kernel patch required for the validated physical unplug/reconnect result.
  Physical motherboard USB-root boot remains unqualified.
